# kiln

A personal knowledge and work system built on Obsidian: unshaped things in, finished things out.

Obsidian first, then Claude, then everything else. kiln is a vault structure that reads well (the blueprint), the flows that keep it current, and Claude skills that follow the same process. It reaches Claude through one Claude plugin, from any folder or from Claudian inside Obsidian.

## Install

Install the Claude plugin once, for your user, from this repo's marketplace. The commands are the same in Bash and PowerShell:

```
claude plugin marketplace add Kieranties/kiln
claude plugin install kiln@kiln
```

Then follow [Getting started](https://kieranties.github.io/kiln/guides/getting-started) to set up your vault with `/kiln:setup`.
